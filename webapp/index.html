"Recreated state" is built from the real field names captured from an actual TFT session (game_info.tft_gold, tft_shop, tft_board, tft_bench, tft_roster, tft_item_select, tft_carousel, etc). Anything captured that isn't rendered into a dedicated card yet shows up under "Other live data" as raw JSON, so nothing is silently dropped. "Last event" on the right shows exactly the most recent message, unmodified - every message still updates the cumulative state on the left, even ones that flash by too fast to see individually there. The Board grids' row/column layout is inferred (7-wide hex grid, 1-indexed cell numbers, row-major) rather than documented anywhere - if a unit's rendered position doesn't match reality, that math needs correcting. Champion/item names are looked up against Community Dragon's TFT data (fetched once from /names.json) with a heuristic cleanup fallback for anything not found there, like PvE-variant names.
