"Recreated state" is built from the real field names captured from an actual TFT session (game_info.tft_gold, tft_shop, tft_board, tft_bench, tft_roster, tft_item_select, tft_carousel, etc). Anything captured that isn't rendered into a dedicated card yet shows up under "Other live data" on the right (one card per key, always its latest value only - not a growing history) as raw JSON, so nothing is silently dropped. "Last event" above it shows exactly the most recent message, unmodified - every message still updates the cumulative state on the left, even ones that flash by too fast to see individually there. The Board grids' row/column layout is inferred (7-wide hex grid, 1-indexed cell numbers, row-major) rather than documented anywhere - if a unit's rendered position doesn't match reality, that math needs correcting. Champion/item names and icons are looked up against Community Dragon's TFT data (fetched once from /names.json, icons hotlinked directly from their CDN) with a heuristic text-only fallback for anything not found there, like PvE-variant names. Active/inactive traits are computed client-side from a board's champions (there's no dedicated trait key in the event stream) against each trait's tier thresholds from Community Dragon, matched by trait display name rather than internal apiName - that's what a champion's own trait list actually contains - and shown as a vertical icon sidebar to the left of that board, sorted by tier cap ascending, same as TFT's own trait tracker. The augment/item choice card checks Community Dragon's augment table before its item table, since TFT reuses the same tft_item_select key for both; augments are items flagged isAugment in Community Dragon's data, not a separate table. Both were verified against a live fetch of Community Dragon's data, though not against a live TFT match from this environment. Every player's board, bench, and item bench - including your own and the current opponent's - live under "All players", one tab each, rather than separate dedicated cards; the board/bench there come from tft_board_players (a periodic whole-lobby snapshot, only the latest one is shown) instead of the tft_board/tft_bench keys, which still update every round but are otherwise only visible as raw JSON under "Other live data" now. "Load demo" replays a small anonymized excerpt from a real captured session through every renderer above, so this page shows something even with no bridge, no relay server data, and no game running.
